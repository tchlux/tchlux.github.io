# PA Psychology Law Benchmark Scorecard V1

Use this rubric when comparing an old item against a rewritten item on the same seam.

## Axes

### `R` Reasoning burden

- `0`: mostly direct recall
- `1`: one extra inference or comparison
- `2`: requires preserving multiple clauses, competing rules, or ordered steps

### `C` Cue resistance

- `0`: answer structure is exposed by recognition or option-elimination
- `1`: some cue leakage remains
- `2`: solver must reconstruct the rule without visible rescue structure

### `F` Fact-flip sensitivity

- `0`: changing one fact would not materially change the answer
- `1`: one fact matters, but the item still mostly tests topic familiarity
- `2`: one small fact change would predictably flip the legal result

### `L` Context-free legitimacy

- `0`: missing facts or ambiguous key
- `1`: mostly answerable but still underspecified or misleading
- `2`: self-contained and uniquely keyed

## Use Notes

1. Compare only items that test the same seam family.
2. Score the old and new versions independently before discussing preference.
3. If the new item improves `R` or `C` but loses `L`, it does not count as a real improvement.
4. Treat the scorecard as a structural benchmark unless a fresh blind run is also available.
