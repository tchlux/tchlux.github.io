## Scorecard

Each paired comparison uses four `0-2` axes:

- `R`: reasoning burden
- `C`: cue resistance
- `F`: fact-flip sensitivity
- `L`: context-free legitimacy / uniquely keyed answer

Maximum composite score: `8`.

This matched scorecard is a manual comparative benchmark. It is meant to measure structural improvement on the same seam families, not to claim a fresh external model run over all `60` new items.

## Why The New Set Is Better

1. It keeps the source ratio while removing half the questions, so each surviving item has to carry more discrimination value.
2. It moves away from option-recognition and toward exact-rule reconstruction.
3. It uses neighbor-rule interference, competing dates, and live-condition failures more often than isolated recall prompts.
4. It keeps legitimacy attached to each item so ambiguity review is part of the dataset, not a separate undocumented judgment.

## What Was Intentionally Reduced

- pure fee-amount recall
- broad title-or-definition prompts with no competing near-miss
- isolated administrative facts that could not be turned into a cleaner applied question
- recognition-heavy MCQs where the right structure was visible as soon as the options were shown

## Limits

1. This is a manual structural benchmark, not a fresh blind run over all `60` items.
2. The compact set is intentionally medium-hard to hard overall; not every item is designed to be the single hardest possible prompt in the corpus.
3. The main achievement is better discrimination per question at the same source split, not exhaustive reuse of every old seam.

## Prior Blind-Evaluation Evidence Already In This Workspace

The earlier blind `mini` experiments in [gpt-5.4-mini-hard-question-answers.md](/Users/thomaslux/Library/Mobile%20Documents/com~apple~CloudDocs/Documents/2026%20Alex%20PA%20Psych%20Test/drafts/gpt-5.4-mini-hard-question-answers.md) already showed the directional pattern this benchmark is aiming for:

- standard or recognition-heavy MCQs often became too easy
- deadline, exception, and neighboring-rule short-answer items produced more exact-rule failures
- the best failures were not random; they clustered around real near-miss rules

That prior evidence is why the new compact set is deliberately shorter and more reconstruction-heavy.
