# Discarded Directions

- Broadly expanding the number of hard MCQs before reviewing current seam coverage. Rejected because the current bottleneck is item legitimacy and difficulty calibration, not raw count.
- Simple child-abuse training hour questions. Rejected because they were too recall-heavy without enough ambiguity-resistant reasoning.
- Standalone fee-amount questions. Rejected because they depend on rote recall and do not support the “authentically challenging” target well.
- Claiming a fresh blind evaluation across all `60` items in the same session. Rejected because the available evidence here is a manual structural benchmark plus earlier archived blind-run results, not a new full-run measurement.
- Preserving both `120` and `60` datasets in the app on the first pass. Deprioritized because the user asked to get the new questions live first, and a mode switch would add avoidable UI and sync complexity before the core rewrite is even proven.
